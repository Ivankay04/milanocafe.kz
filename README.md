# Сайт кафе «Милано» — milanocafe.kz (GitHub Pages)

Всё лежит в одной папке:
- `index.html` — русская версия, `kz.html` — казахская. Вручную не править: обе собираются из `template.html` командой `python3 build.py` (правки делает Claude).
- `assets` — иконки, фото и видео. Имена файлов — в `ФОТО-И-ВИДЕО.md`.
- `CNAME` — домен для GitHub Pages, не удалять.
- Заказы, брони, обед дня и стоп-лист обрабатывает сервер на Railway (репозиторий `milano-bot`), адрес — в `build.py` → `API_URL`.
